# Итерация 00001

Дата: 2026-04-16

## Что сделано

- Добавлен каркас репозитория: `apps/api`, `apps/bot`, `apps/worker`, общий пакет `kov/*`.
- Поднят базовый стек:
  - FastAPI API с роутами: health, users, scenarios, mood, habits, reports, schedule, rag_scan, rag_search, llm proxy, dialog, techniques.
  - Telegram-бот (aiogram) с командами `/menu`, `/interview`, `/rag`, `/mood`, `/habits`.
  - Worker (apscheduler) с тикером напоминаний.
- Реализованы основные компоненты RAG:
  - `rag_scan`: загрузка PDF, извлечение текста (pypdf), чанкинг, fake-эмбеддинги, индексирование в Qdrant, сохранение артефактов в S3.
  - `rag_search`: планирование запросов (rule-based), multi-query retrieval в Qdrant, дедуп, расширение контекста по соседним чанкам из Postgres, Telegram-safe разбиение ответа.
- Добавлены docker-compose для dev и отдельный `docker-compose.e2e.yml` для e2e.
- Добавлены unit-тесты и e2e-тест (scan→search) с поднятием инфры.
